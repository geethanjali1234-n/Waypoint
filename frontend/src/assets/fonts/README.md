# Self-hosted Route-line fonts

Latin WOFF2 subsets supplied by Google Fonts, fetched 2026-10-12.

- Fraunces: weight 500, optical-size axis 9?144.
- Instrument Sans: variable weights 400?600.
- Combined font payload: 64,804 bytes. No runtime external font requests.
- Both use the SIL Open Font License 1.1; the unmodified license files are included here.

Upstream sources:
- https://github.com/google/fonts/tree/main/ofl/fraunces
- https://github.com/google/fonts/tree/main/ofl/instrumentsans
- https://fonts.googleapis.com/css2?family=Fraunces:opsz,wght@9..144,500&display=swap
- https://fonts.googleapis.com/css2?family=Instrument+Sans:wght@400..600&display=swap

System/Georgia fallbacks cover characters outside these Latin subsets.
